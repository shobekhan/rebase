### Graph

git log --graph

Good tool to show how conflicts arosed and were merged.

### See the last 5 commits

git log -n 5

### One line

git log --oneline

### search in logs

git log --grep 'foo'

### search in logs (shows the changes)

git log --grep 'foo' -p

### search in logs (shows the changes, in the specific files)

git log -p src/index.ts
